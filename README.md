# 万界武库 v1.7.9

整理剧情、管理能力成果与长期档案的 SillyTavern 扩展。支持原文状态栏、长期子表、漫漫长路道场与太始天诸界管理。

## 安装与更新

在酒馆扩展管理中使用仓库地址 `https://github.com/feiluoze/wanjie-wuku` 安装。已安装的玩家点击更新并刷新，面板显示 **1.7.9**。

## 快速上手

1. **接入金手指**：点击「接入金手指」，按功能大类/细分类选择主词条（可在「附加库」勾选辅助规则，也可展开「编辑注入正文」自定义发送给正文模型的内容）。
2. **整理剧情**：正常推进剧情后，点击「整理剧情」或「读取范围」选择楼层整理；也可在「档案更新」区开启自动更新。
3. **日常使用**：顶部导航分为「现在」（状态与长期档案）、「行动」（按词条生成可执行方案）、「背包」（已到手的能力与物品）、「记录」（历史流水与承接）。
4. **余额维护**：通过「核对资源余额」或绑定角色 MVU 变量维护。
5. **词条管理**：选中词条后，点击名称旁的「⋯」可查看/编辑规则、暂停或删除词条。

## 近期更新

### 1.7.9 · 1128 内置词条更新

- 收录 1128 更新包的 13 条主词条和 9 条附加规则。主词条配齐二级分类和原生状态栏，附加规则在附加库内按所属词条分组。
- 新增 8 张长期子表：百艺与绝学、锚定升格名目、持续秘仪、养成名录、调查卷宗、座驾与编队名录、研究成果与蓝图、传世章回。

### 1.7.8 · 词条总览与候选编辑

- 万界网购订单的报价与原文证据分开校验。最新回复的结算回执和状态栏一致时，整理保存会同步兑换点。已按回执入账的楼层不会在剧情核算中重复扣付。

- 一页查看已接入的普通词条、余额和档案摘要。可以依次整理，遇到待确认结果会暂停。
- 查看正文注入的字数估算，并从总览暂停或恢复词条。
- 确认普通整理结果前可编辑候选字段。未通过的候选可在表单里修正字段后重新核对。

### 1.7.7 · 界面和设置整理

- 「AI 连接与方案」按基础连接、任务路由和自定义预设分组。
- 精简首页、待确认区和各模块的说明，常用操作保留在相应页面。
- README 改为快速上手和近期更新，历次变更可查阅 [更新记录](CHANGELOG.md)。

### 1.7.6 · 整理成果读取范围与多词条合并
- 接入金手指支持按功能大类与细分类筛选，附加规则统一在「附加库」选择；支持自定义编辑或还原注入正文。
- 「整理剧情」旁新增「读取范围」，可选最近 N 层或指定起止楼层。
- 「档案更新」支持多词条合并更新：在各词条「更新设置」中勾选「与其他词条合并更新」并设为相同间隔，同轮到期时共用一次请求；若合并回复缺项，自动为受影响词条单独补发。
- 正文切换分支后，失效记录移入长期档案库的「旧分支记录」，切回原回复可恢复。

### 1.7.5 · 档案保存与渠道报错优化

- 酒馆读回旧版本时自动补存一次；检测到版本冲突时暂停覆盖并保留备份。
