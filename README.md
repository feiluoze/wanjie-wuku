# 万界武库 v1.5.7

整理剧情、管理能力成果与档案的 SillyTavern 扩展。1.5.7接入内置词条原文状态栏，标注专属资源并统一余额来源。详见[本版说明](RELEASE-1.5.7.md)。

## 安装与更新

推荐在酒馆扩展管理中使用仓库地址 https://github.com/feiluoze/wanjie-wuku 安装；已安装的玩家点击更新并刷新，面板应显示1.5.7。

手动安装使用完整安装包，将ZIP内wanjie-wuku文件夹放入实际使用的扩展目录，常见路径为data/default-user/extensions/。覆盖前备份；当前仍有未安全保存的数据时，先导出完整档案再刷新。

维护者可使用1.5.6到1.5.7上传包，保留目录结构覆盖安装分支。玩家从仓库更新不依赖GitHub Release附件。

## 使用

- 主界面执行AI整理；存在待确认结果时，先核对并确认保存。
- “当前状态”按匹配的内置原文栏目显示；未确认字段留空。点数、能量、次数标注在资源栏，状态栏余额与资源账本共用；从“核对资源余额”确认正文快照。
- 能量上限保留为原状态主表字段，可用余额由账本维护；已绑定角色MVU时沿用绑定与刷新机制。
- “查看档案”提供搜索、筛选和分页；更多操作集中分批整理、手动补录、余额修正及纠错入口。
- 模型格式失败会保留候选；主动“AI修复未通过项”会消耗所配接口额度，修复后仍需核对。

## 数据与兼容

更新不会自动删除或迁移已有档案，不重新结算旧订单。旧状态栏快照与历史原值保留，当前显示与记忆引用现有资源账本。规则正文改动后不冒用内置版本适配。

安装包不含玩家正文、私有世界书、失败候选、运行日志或API密钥。真实模型返回仍需本地校验，不保证任意模型均成功。
