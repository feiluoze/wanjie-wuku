# 万界武库 v1.5.6

1.5.6采用新版工作台布局并改善可读性、空状态与手机触控；包含1.5.5保存恢复修复。详见[本版说明](RELEASE-1.5.6.md)。

整理剧情、管理能力成果与档案的 SillyTavern 扩展。1.5.5 简化主界面操作，增加明确的档案入口与分类筛选，并合并 1.5.4 的全部累计修复。详见 [更新说明](RELEASE-1.5.5.md)。

## 安装与更新

玩家使用完整安装包，将 ZIP 内 wanjie-wuku 文件夹覆盖到实际使用的酒馆扩展目录；覆盖前备份，更新后 Ctrl+F5。常见路径为 data/default-user/extensions/，已有安装以实际位置为准。

仓库维护者使用 1.5.5 到 1.5.6 累计上传包，将“网页上传内容”中的文件保留目录结构覆盖仓库根目录。原始 1.5.5、保存修复版及用户提供的1.5.5界面版均可直接覆盖；更早版本的玩家请使用完整包。

## 使用

- 主界面执行 AI 整理；存在待确认结果时，先核对并确认保存。
- 点击“查看档案”，或在分类卡片点“查看全部”，可搜索、筛选和分页；打开详情后可返回原列表。
- 分批整理、手动补录、余额修正、规则与纠错集中在“更多操作”。
- 模型格式失败会保留候选材料；无法在本地无损恢复时，可主动执行“AI 修复未通过项”，消耗所配置接口额度，修复后仍需确认。

## 数据与兼容

更新不会自动删除或重写已有档案。通用“种群”改名为“群体”，存储类型及旧字段继续兼容。匹配当前聊天与来源的 1.5.3、1.5.4、1.5.5 待确认缓存可继续恢复。

安装包不含玩家正文、私有世界书、失败候选、运行日志或 API 密钥。真实模型的格式与事实错误仍须校验，不保证所有模型均成功。

## 验证

随包 VERIFICATION.json 提供测试、模拟浏览器、版本与累计覆盖校验结果。本版未在真实酒馆安装验收，未调用真实模型或远程发布。
