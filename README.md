# 万界武库 v1.5.0

1.5 回到武库本体：缩小长档案整理请求，完善执行前校验、结算阶段展示和已有能力物资的操作入口；同时整合全部本地 1.4.9 修复。

手动分批整理位于总览主要操作区；能力与物资按类别展示，可直接以现有条目拟定方案。历史清楚区分记账、角色同步与正文承接，完整规则及流水按需展开。详见 RELEASE-1.5.0.md。

- 文明与族群分开：文明筛选、首页卡片及归属选项只展示文明主体；族群资料仍保留。分类由预设和本地处理承担，不增加玩家设置步骤。
- 世界书导入依据原文明确的文明主体分类，社会生活、交通、交易、职业等专题不自动变成独立文明。
- 后录入的文明可按已有、明确的地域与组织关系归拢早先档案；同世界精确地点名可辅助关联，多义、跨世界或失效关系不猜测。
- 增加“AI 修复未通过项”及专属修复预设，只发送失败候选与核对材料，不重新整理整本书。修正后重新校验、预览确认；失败或取消保留候选。
- 改进通用/专用字段包装、名称与值格式兼容，合法字段可独立保留；全失败结果及未完成候选保留本地恢复缓存。
- 改进合并词条的原文引用、同批组织关联与关系诊断，保留单世界约束、人物身份与程序专管字段保护。
- 部分保存后保留本批未完成项，已保存项不再重复提交；全部完成后才推进批次。世界书构建可选同时整理普通人物，不自动授予眷属身份。

## 安装与上传

玩家使用完整安装包，解压后将wanjie-wuku目录放入酒馆扩展目录；覆盖前备份已有扩展及聊天档案，完成后Ctrl+F5。

仓库网页上传使用累计源码上传包：包含相对已交付1.4.6新增或修改的源码，保留目录结构覆盖仓库根目录；可用于1.4.6及之后本项目版本升级到1.5.0，无需叠加中间修复包或删除文件。具体文件数见随包清单，低于网页100文件限制。

不附带玩家正文、私有世界书、失败候选、运行日志或API密钥。此前误建或遗漏的档案不会被更新包自动删除或重写。AI修复使用玩家已配置的连接与备用API，会消耗额度；未通过部分不自动循环调用。自主发展、历时及创作草案仍走原任务续跑。

## 验证

全量单元测试、版本一致性、模块导入依赖、累计覆盖一致性、ZIP及SHA256检查见VERIFICATION.json。桌面1440px和手机390px模拟宿主检查文明导航、族群保留和地域归拢，外部请求与真实模型调用均为0。本次发布包未在真实酒馆安装，未验证真实模型成功率。

旧记录未带文明/族群类别时，导航仅对明确文明命名和玩家登记来源作保守兼容显示；未知族群记录仍保留，不自动改写档案。没有明确归属依据的资料保留公共或待明确区域。
