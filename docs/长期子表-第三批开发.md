## 保存与消费

继续使用 ChatStore、稳定 archiveId 和现有候选确认流程；只在当前原文指纹匹配时启用。状态栏主表保留当前摘要，子表展开需要跨回合接续的对象，不复制同一份长清单，不再建一套余额。

本批添加的是保留/更新声明与事实边界，沿用既有校验；不会用本地脚本自动推演装备性能、计算战意、创建神话或执行构筑。字段结构合法不代表 AI 对故事机制的判断一定正确，仍需核对来源与候选。

普通挥剑、每次借力、稳定运行与重复识别不逐条常驻。有持续效力、独立权限、未完事项、真实重要增量时更新原对象。没有新事实应返回空变化。

不自动迁移、删改或合并旧通用档案，不新增 SQL 或 MVU 存储，不修改资源钱包、UI 和正文注入规则。已有 event 子表的按需注入行为沿用原实现；本批不新增逐次事件流水表。
