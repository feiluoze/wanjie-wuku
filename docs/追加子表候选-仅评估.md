# 追加长期子表：首批实现与后续候选

1.6.0 已实现首批9项，准确范围见 [长期子表说明](长期子表-1.6.md)。以下表格保留原评估意图，非全量开发承诺。自我束缚以当前原文已成立的宣告与实际兑付为准，不强加延期兑付或偿还机制。

这不是开发清单全选。先使用原文状态主表，仅在正文产生需要独立跟踪的对象、义务或未兑现事项，且总览不足以准确承载时，再逐项适配。当前阶段不导入旧版137张表，不建立外部SQL服务，不让玩家维护技术编号。

| 词条 | 候选子表 | 建立与保留门槛 | 顺序 |
|---|---|---|---|
| 万界网购 | 订单与待领取资产 | 存在未交割、分批领取或持续委托时，按订单ID持续追踪；普通已完成小额购物不逐条常驻。 | 优先 |
| 升变之印 | 已选分支与任务进度 | 同一目标有多个有意义分支，或暂停后需恢复进度时；不保留所有临时推演。 | 优先 |
| 天人骨血 | 永久特征与统合结构 | 新增永久适应或复合结构时；普通恢复过程更新状态栏，不逐次建表。 | 优先 |
| 熟练度状态栏 | 技能目录与关键里程碑 | 技能需独立成长时；普通重复练习合并，突破与破限保留关键节点。 | 优先 |
| 先祖投资人 | 投资与独立史线 | 投资标的形成独立传承或历史变化时；当前资产只留最新权属。 | 优先 |
| 道途 | 已成立契约与本质跃迁 | 形成独立道途契约或关键跃迁时；日常践行不逐次常驻。 | 优先 |
| 自我束缚 | 有效约束与待兑现权益 | 存在持续义务、解除条件或未兑付收益时；临时想法不入表。 | 优先 |
| 心渊 | 永久积累与当前探索 | 需要跨轮保留的遗藏、永久渊痕和未完探索；普通战斗与重复节点不无限拆条。 | 优先 |
| 生命球 | 生命库 | 存在可调用的独立生命信息与重要变化时；重复采集更新原对象。 | 后续 |
| 拓印 | 可使用拓印库存 | 拥有不同对象、品质或用途的长期拓印时；重复描述不增加库存。 | 后续 |
| 万灵图鉴 | 已收录个体与编队 | 可独立调用或持续成长的精怪与编队；重复露面不建新对象。 | 后续 |
| 模板 | 有效模板与装配关系 | 存在多个可切换模板时；一次性表现不当成新模板。 | 后续 |
| 挂机 | 持续任务与待领取成果 | 存在持续任务、战区或尚未领取的真实产出时；每一轮普通进度不独立建档。 | 后续 |
| 咨询法 | 长期咨询对象与关键认识 | 后续仍需调用的对象档案和重要认识；普通对话不逐句保留。 | 后续 |
| 败家生财 | 按资产身份保存的库存与必要支出凭据 | 当原文总览已难以区分账户、位置或数量时追加；普通小额流水归组，程序防重凭据不全量注入。 | 按需 |
| 每日情报 | 当前锁定与未完成线索 | 只有被锁定、长期影响或尚待处理的重要情报；过期日常消息不无限累积。 | 按需 |

1.6 底座已实现稳定ID定位、声明式更新、来源检查与按需浏览；可撤销迁移与语义自动合并尚未实现。对象表更新现状，关键事件保留历史；日常细节归组，不无限追加。任何新增机制限制都必须来自当前原文。所有旧数据迁移均需单独预览与确认。
