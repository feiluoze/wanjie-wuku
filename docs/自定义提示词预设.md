# 自定义提示词预设（1.6.4）

在“AI连接与方案”顶部点击“管理／导入预设”。可导入酒馆Chat Completion预设JSON或武库导出的预设；酒馆暴露预设管理接口时，也可直接复制已经安装的预设。复制只读，不切换或改写主聊天预设。

## 操作

1. 导入后逐块勾选，使用上移／下移调整顺序。展开可修改正文和system/user/assistant角色。
2. 建议取消与内部任务无关的思维链、字数、文风和续写块。预览能检查块与武库任务的位置，并验证支持的宏；预览是结构示意，不包含真实玩家档案，不调用模型。
3. 保存快照，再在管理页为需要的任务选择该预设并保存任务选择。默认全部关闭，导入不会立即应用。自动与手动整理、该任务的失败候选修复共用“整理与自动更新”；太始天专职任务单独选择。
4. 重新编辑会回显已经保存的内容、选择和顺序。关闭任务或删除预设后恢复武库原提示，删除前需确认。

## 请求行为

导入保留文本块的角色及顺序，识别prompt_order中的100001、100000顺序；没有这两个时使用首个顺序表，无顺序表时沿prompts数组。未列入顺序或原本禁用的块默认不选。上下文marker不当作普通文本发送；chatHistory位置放入武库本次任务，仅放一次，没有启用该位置则追加任务。角色、世界书、示例对话插槽不重复展开，数据仍由武库本次选定范围提供。

原任务的消息和数据完整保留，末尾追加内部任务格式提醒；返回仍通过现有JSON、字段、归属、防重复、余额及保存确认流程。提示词无法保证模型永不跑偏或不拒答。独立API直接发送组装后的消息；沿用酒馆连接时通过已有generateRaw消息数组接口传递，酒馆自己的配置仍可能影响最终请求，不承诺绕过主预设或渠道限制。

请求诊断记录预设ID、组装后消息数及字符数，不记录预设中的凭据。导入仅保留提示块，不采纳原文件中的模型、API地址、Key、采样参数或扩展脚本。单份文件最多2MB、256块，单块最多200000字符；最多20份，库总量最多4MB。加预设后组装消息上限1600000字符，实际还受模型上下文限制。

## 宏边界

支持`{{user}}`、`{{char}}`、`{{setvar::名称::值}}`、`{{getvar::名称}}`及对应的setglobalvar/getglobalvar，以及`{{// 注释}}`。这里的变量都只在本次请求内保存；getglobalvar也不读取酒馆真实全局变量。未初始化的变量、未闭合和不支持的宏在请求前明确报错，玩家可关闭对应块或编辑为普通文本。不会调用宿主substituteParams、执行JS、运行斜杠命令或加载远程脚本。

## 来源与验证边界

借鉴[故事神谕84884eb的提示块选择、独立快照与任务适配设计](https://github.com/namelessone88/story-oracle/blob/84884eb505b3b891fa2969785cb838921d3eebb7/index.js#L22764)，采用独立实现，没有复制其代码或内置破限文本。仓库未提供可确认的许可证，因此不移植其素材或提示词。

预设接口参考[SillyTavern 06bde93的PresetManager](https://github.com/SillyTavern/SillyTavern/blob/06bde939fb1e9c4c8d8641d810f0a916b5bce127/public/scripts/preset-manager.js#L531)，运行时探测getPresetManager/getPresetList/getCompletionPresetByName；接口不可用时明确提供JSON导入入口。此源码快照不代表玩家安装版本，未据此提高最低版本要求。

自动测试覆盖导入顺序、禁用块、角色、快照往返、宏隔离、任务分流、连接关闭、损坏文件、库版本冲突、凭据保留、原任务不丢失、独立API与酒馆消息数组。模拟浏览器覆盖导入、选择、排序、预览、保存、刷新、任务选择、导出、删除及手机布局。真实酒馆、真实模型拒答改善与用户最终验收需另行确认。
