# 1120 内置词条更新

1120 世界书的 177 条规则已接入。内置库保留了上一版的「自动填坑」，合计 178 条。新增 26 个主词条和 17 份辅助详解。太始天沿用专用模块入口，万界武库思维链 V3 接续原 V2.1 的内置编号。

旧词条沿用内置编号。新版状态栏随原文同步，能明确对应的字段继续使用原编号。旧档中已经保存的字段、子表记录和余额保留。新增主词条各有一张长期记录表，按对象保存真正需要后续调用的事实。辅助详解随主词条使用。

万象轮转的刷新次数和词条构筑的待抽次数进入原有余额框架，初始数量以剧情确认为准。指数增长的旧余额保留，按新版区分自然升阶与直购。念气体系额外记录正文明确出现的凝炼次数。

本地已检查目录、配置接入、资源与主栏绑定，以及 4 个 1108 旧规则样例的升级。真实酒馆加载、旧聊天里的全部历史数据、真实模型填表及结算表现待实际试用。

后续补齐了人生模拟的刷新时间、蝴蝶效应的累计收支和指数增长的双倍回馈状态。念气余额核对支持原文的科学计数表示。词条构筑、道生万法、预支明日及商贾、领袖、赤丝戏梦补上对象区分字段，已有档案仍沿用原编号。

另用本机酒馆安装目录中的 1.7.0 内置库作为旧版样本，在内存中确认 129 条规则可接续更新。本机安装目录与本地开发源码是两个副本。
