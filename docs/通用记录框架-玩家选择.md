# 通用记录框架：由玩家选择长期记忆范围

随1.6.3仓库更新提供；本地自动化与模拟宿主验证通过，真实酒馆验收另行进行。

## 怎么选择

新接入：选择主词条后，在下方勾选需要长期保存的内容，再确认接入。框架按玩法给出推荐，可以改选，也可以全部取消。切换主词条查看时，本次未保存的勾选分别保留。

已经接入：进入词条管理页，点击“选择记录框架”。保存按钮在弹窗底部常驻；不必滚到长列表末尾寻找。每个聊天的每个词条独立保存选择，备份和恢复随当前档案一起保留。

七种框架：

| 框架 | 长期保存 | 不做什么 |
|---|---|---|
| 能力与成长 | 已成立能力、永久强化、实际效果、使用条件、重要深化 | 不逐次记录施展和练习，不编等级和伤害公式 |
| 重要资产 | 重要装备、物品、种源和可调用权益及真实去向 | 不记普通杂物和每笔收益，不另建资源钱包 |
| 成员与编制 | 重要伙伴、负责人、独立军团的身份、能力、职责和关键经历 | 不给普通人口逐人造册，不为召回或重构增加副本 |
| 区域与建设 | 重要基地、领地、农田、工坊和已启动的重要工程 | 不逐次记录浇水、搬运、生产批次，不推算后台产量 |
| 知识与档案 | 可复用知识、配方、历史信息与研究成果，区分事实和预测 | 不保存每轮问答、演算与普通检索 |
| 长期线索 | 有后续行动价值的坐标、关键未知和探索目标 | 不把路过地点与过期日常消息全部常驻 |
| 持续安排 | 已成立且重要的授权、契约、保护、封存与规则 | 不按每次修改拆流水，局部安排尽量附所属对象 |

八类玩法只用于推荐，不限制词条玩法。源堡可以选择种田经营记录，直接战斗词条也可以因实际剧情选择成员或建设。自定义来源可以手选框架，不根据与内置词条同名来套用原文权限。

## 源堡示例

选择“区域与建设、成员与编制、知识与档案”后：

- 东区灵田、育种园、炼金工坊按重要对象各自保存，用途、供给、负责人和当前瓶颈写在对应详情；扩建更新原对象。
- 艾琳作为重要负责人独立留档；普通工人可以按真实群体汇总。
- 旧塔之战继续使用源堡原来的“历史与信息记录”，不再新增同名通用知识副本。
- 只属于灵田的灌溉安排写在灵田详情；跨区域且重要的通行规则，玩家可另选“持续安排”保存一次。
- 原领域总览继续摘要当前收纳、重要记录与长期安排，不需要复制各对象整份详情。

框架不会凭空生成能力、领土、居民和生产成果，原文已有完整权柄也不会因为模板字段而被加上新门槛。重要性与事实仍由正文、原规则和候选核对共同确定。

## 关闭与旧档

全部取消：停止新增框架记录，原状态栏继续工作；没有原状态栏的自定义词条不会因此凭空获得主表。

关闭某类：停止自动整理该类档案，已经保存的对象和历史不删除。可以从档案库查看、手动编辑；再启用后继续原身份。关闭记录框架不改变已有的正文记忆选择，是否注入正文仍在“正文记忆”中设置。

旧聊天未保存框架选择前，保留原有记录方式。保存后优先复用已有专属表；已有收拢分类只兼容已有对象，不恢复成可以任意新增的流水表。能明确归到框架的旧分类随相应选择继续更新，未映射的旧过程分类仍供查询和手动维护。

源堡旧版资产档若已存在，选择“重要资产”后可沿原档更新；同名对象不能再作为通用资产复制一份。没有自动搬迁、合并或删除。确实同名的独立对象应在名称中说明来源或类型，程序不会猜测身份。

## 实现边界

沿用ChatStore的每词条档案，不引入外部SQL或MVU迁移。`recordFrameworks`仅保存版本和选择的框架ID。schema仍使用现有文字字段与稳定档案ID；同一对象部分更新、省略字段保持、真实状态转换和已有来源校验继续生效。

整理请求只提供启用框架的可写schema；关闭框架的旧档只提供身份目录，不重复发送其完整详情。不允许用无recordId的通用成果或关闭的分类绕过选择。兼容的旧通用对象仅在能明确对应到已选框架时沿原身份接续。

框架调整在当前聊天与状态版本内事务保存。词条切换、状态版本过期以及尚有整理任务或待确认候选时拒绝覆盖。重新接入会保存本次明确勾选，也兼容没有框架表单的旧调用。

已核114个普通内置主词条可以分别选择七种框架；已有50个子表声明的专属字段按框架归类复用。内置分类按原文指纹推荐，原文变化后不凭名称继承推荐。太始天和漫漫长路保持专用结构与入口，本轮不叠加通用模板。

自动化证据与模拟浏览器检查见本地development-record-frameworks；真实酒馆中的安装、聊天切换、页面重载、实际API更新和真人体验尚未验收。自动验证不代表模型能够完全正确判断重要性和同义对象。

## 本地验证结果

源堡、战争天网、绝对命中三个试点通过后，已铺设到114个普通内置主词条；每个词条分别验证七种框架，共798种选择组合。1750项测试中1736通过、14个缺失样本跳过、0失败。新框架19组及旧子表24组模拟浏览器检查通过，覆盖1440/390/320px、深浅主题、常驻保存、关闭/重新启用、旧档查看、新接入、切换词条保留草稿与重新接入。外部请求和付费模型调用均为0。

全部七种框架同时选择、无正文且空档案的114词条请求基线，最大为神圣几何25077字符；实际剧情与档案会增加输入，原有120000字符发送前检查保持。此测量不代表模型token上限或真实请求成功率保证。
