# 全部子表必要性复审（当前本地清单）

本轮将上次的35类默认独立子表收至26类，撤下9类。23个词条均已复查，其中20个保留独立子表，等价交换、我全都要、多倍收获系统改为只用原状态栏。

历次声明共75个分类：当前26个默认分类，49个仅兼容旧档的分类。兼容分类不等于仍推荐新增的表。没有删除玩家记录、运行历史或未知字段，不自动迁移、合并，不改世界书。

漫漫长路另有8个原有模块（领地、宗门、功法、肉身、物品、灵体、舰队、项目）的表格视图：只是显示原档案，不属于这75类新增适配；此次不新增或拆分任何模块。原文状态栏也不计作追加子表。

## 保留门槛

必须有独立身份、会在不同回合单独变化、其详情超出原状态栏承担的当前摘要。单纯已有字段、能够统计、可能以后有用，都不构成建表理由。技能库、永久馆藏等原文明确按需调阅的多对象库存，可以保留；普通收支、当前自身状态、观察流水、同一对象的阶段副本不应默认铺表。

保留也不等于每回合更新：只有真实新增、变化或结束才改原行；没有变化不写。原状态栏只摘要和引用，详细事实存主对象一处；同一事实不双份维护。

## 本轮撤下的9类

| 词条／原分类 | 归并去向 | 撤下原因 |
| --- | --- | --- |
| 升变之印／待选分支与确定报价 (`branches`) | 并入目标详情 | 分支和报价从属于同一升变目标，不需要第二个长期身份。 |
| 天人骨血／统合生命结构 (`life_structures`) | 原文统合成果 | 同一身体的复合性质，原状态栏已有统合成果；不按每次组合建一行。 |
| 败家生财／实际支出与返还 (`spending`) | 原文资产总览／既有运行历史 | 不把每笔支出和返还扩成常驻成果；未完成持续安排由原栏目接续，未到账不记余额。 |
| 万灵图鉴／影页与事件 (`shadows`) | 原文重要影页 | 未正式收录的观察对象及线索已有原栏目，不把普通接触升级为常驻成员档。 |
| 模板／个人位格与真名 (`personal`) | 原文当前个人模板／晋升记录 | 自身位格、阶段和真名属于自身状态；已解锁的重要成果继续保存，不每层另起长期对象。 |
| 等价交换／已成立交换与付出 (`exchanges`) | 原文最近交换／当前暂存 | 本批没有证明需要独立于原记录的新身份；保留交换资格、尺度与交割条件，不另做成交统计。 |
| 我全都要／奖励结算组 (`reward_group`) | 原文既得收益／待兑现／重要兼容 | 原栏目已经承接整组奖励与兼容；不按任务再铺奖励统计。 |
| 多倍收获系统／待兑现权益 (`retained`) | 原文暂存收益 | 原文专门规定仅剩余待兑现收益跨回合显示，独立权益表是重复维护。 |

| 力量构筑／大源体系 (`major`) | 原文重要大源·详情及待构筑安排 | 原生状态栏已支持多份具名详情、按名称单独接续，无需再建同构子表。 |

分支只在已存在的升变目标详情内接续；没有实际目标时，未取得的候选仍放原文“已记分支”，不为了装分支强建已得形态。原文暂存、统合、位格等应保留的重要事实仍需要更新，撤表不等于不记。

## 实现和验证边界

本轮修改默认声明、请求写入范围和无默认子表时的空区块显示；既有存储模型不变。明确 `operation:insert` 不能新增已收拢分类；未带 operation 的旧协议仍保持兼容，因此不是对旧协议新增行为的底层全面禁令。新提示词明确不能用通用成果或事件重新生成已撤下的统计。

旧版已暴露的 related_details 字段继续接受旧档局部更新，其他字段省略时保持原值。兼容不等于自动将旧内容复制入原状态栏，也不进行无依据的数据迁移。

当前版本仍为1.6.1；仅本地修改，不提交GitHub、不安装、不打包。自动测试与模拟宿主结果见本地验证记录；真实酒馆、多插件共存和玩家验收尚未执行。

本轮验证：1408项测试中1394通过、14跳过、0失败；模拟浏览器156组默认子表检查及18组撤表后状态栏/旧档检查通过，无脚本异常、无横向溢出、无外网或付费模型调用。原文状态栏、内置规则、核心存储、版本文件以及漫漫长路表格源码和测试均核对保持不变；UI仅增加无默认表时的空区块隐藏条件。
