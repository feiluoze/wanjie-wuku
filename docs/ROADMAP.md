## 1.3.1 已实现，等待真实宿主验收

- 世界与人物分别选择、分别预算；聊天请求拆为独立 system 记忆块，文本请求保留分块边界。
- 自动选择人物仅限明确提及的人物，提及世界不连带全部居民；保留重 roll 来源校验与单次发送确认。
- 人物设定增加外貌、性格、经历、动机、表达方式、喜好、战斗方式及日常技艺；跨批次追加设定须预览确认。

- 后续仍需：真实模型提取质量、单人物专用补全流程、来源版本差异对照、更大档案按字段分层选取，以及既有 W01–W04/A01–A06。
