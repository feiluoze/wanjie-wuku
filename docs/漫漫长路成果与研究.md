# 漫漫长路：成果与研究

道场首页默认显示简报，集中查看本体修行、本次变化、进行中的事项、已可用的研究成果，以及现有设施与实物。八部分类和表格仍可随时切换。

## 研究与工程

研究页将同一课题分成两部分：

- 已经可用的成果：已验证发现、方法、图纸、工艺和阶段成果。
- 课题进度与缺口：目标、当前阶段、未解决条件和已确定的后续安排。

课题可以保持“进行中”，同时拥有已经可用的成果。它们共用原档案，点击详情可以查看完整内容和成长记录。

## 原理与法式

功法简报按档案中填写的共同原理组织。同一原理下面分别展示各个方法的理解程度、衍生用途、实际效果和使用条件。各方法保留自己的档案与历史。

## 成果脉络

在“关联成果”中填写已有档案名称。保存后，插件记住对应档案的编号，改名后仍能找到原对象。关联的对象后续建档时，也会接上已有记录。

点击“成果脉络”，可按原理与方法、研究与设计、设施与实物、修行与人物查看关联内容。页面会展开两层已记录的关联；仅在同一段剧情出现的对象仍分别记录。

## 数量记录

法器丹药表新增“实际产出”“已交付”“当前库存”三个栏目，分别保留原文的数量、单位和统计范围。

旧档的数量说明原样保留。库存没有明确记载时，表格显示“数量原文”；产能、产出和交付量分别展示，库存等待剧情给出。

## 接着研究或改良

点击“继续此课题”“基于此参悟”或“基于此改良”，拟定窗口会展示已有所得、待解决问题及相关档案。生成方案时，也会优先携带这些内容与两层关联档案的详情。超过现有详情预算的内容沿用原有省略方式。

## 使用研究成果

已有所得的课题，在简报和表格中都有“使用研究成果”入口：

- 安排试用：带着已有方法或设计，安排试用对象、步骤、条件和观察重点。
- 据此制造：结合图纸、工艺、现有设施与材料，拟定制作或改造方案。
- 用于修行：结合研究所得、当前境界与既有能力，拟定修行路线。

选择用途后，先进入方案编辑页。窗口展示原课题的目标、阶段、已有所得、待解决问题、后续安排及关联档案；补充这次想做什么，再点击“生成方案”。生成使用当前配置的 API。

课题中的成果仍保存在原档案中。方案按现有流程确认采用，实际试用、制造或修行结果随后按剧情记录。
