# 万界武库 1.4.8 · 文明与族群归拢修复

- 修复把所有inhabitants记录都列为文明导航的问题。分类预设明确区分文明主体与族群资料，正文社会专题不再自动成为文明。
- 世界书构建按本批明确的【文明】主体标记文明；未标明为文明的新族群候选不因模型误写类型被升级成文明。后续片段复用已确认的同一主体身份。
- 文明筛选、文明卡片、文明计数及文明归属选择只列文明主体。已有树人、妖精、居民群等资料仍保留在档案中。旧记录没有新类别时，仅用明确文明命名及玩家文明登记来源作保守显示兼容，不写回或删除数据；不明对象继续保留。
- 文明最后录入后，先前保存的地点、族群、势力和人物可按同世界已有地域关系、组织关系及明确地点名称在页面归拢。只使用现有ID及精确名称；多文明共处、归属不明、无效ID、跨世界或循环关系不猜测，继续显示在公共或待明确区域。
- 分类由预设及本地处理承担，不增加玩家分类步骤，不需要重新跑整本书。手动登记文明的原有入口保持不变。

完整安装包含此前1.4.7与1.4.8全部修复，版本保持1.4.8。累计网页上传包以已交付1.4.6为基线，可覆盖此前本项目1.4.8累计版本；保持路径上传，无需删除文件。玩家安装包解压覆盖扩展目录后Ctrl+F5；本次未在真实酒馆安装或改动玩家档案。

验证：1087单元测试通过、13跳过、0失败。1440px及390px模拟宿主浏览器中，2个文明、3份族群资料，导航仅显示2个文明，族群仍在对应文明下，布局操作未改变存档，外部请求及模型调用均为0。真实玩家档案的精确归属尚未实机验证；资料没有明确地域依据时不会承诺全部自动归拢。
