# 太始天剧情时间触发设置

开发源码已接入；此前交付的 1.4.1 ZIP 不包含本次改动。没有安装、发布或进行真实付费模型测试。

入口：太始天 → 自主发展 → 高级·按剧情时间自动演化。

先开启允许 AI 合理创作发展候选，再选择已有世界、时间来源、间隔和单位，点击读取时间测试。测试不调用模型，也不保存档案。首次启用必须成功读取当前时间，以它作为起点，不补算历史。

来源支持当前角色回复的自定义标签，例如 `<剧情钟>纪元618年-07月-12日-14:40</剧情钟>`；也支持现有 MVU 的只读变量路径，例如 `/世界/时间`，从 stat_data 根开始。不自动修改正文预设，不写角色变量。多个标签读到不同时间时跳过。

日期支持标准年月日（公历月长与闰年，可带纪元名称）或剧情日序 `第3天 14:30`。间隔可选分钟、小时、天、周、月、年；月和年要求标准年月日及整数间隔。小时和分钟要求来源包含时分。外界时间可以填写内部倍率，内部时间不再重复乘倍率。

仅在新角色回复后检查阈值。达到阈值时按实际累计历时生成一次候选，不逐个补跑错过的周期。候选必须全部核对通过并由玩家采用，时间基准才一起前移。无新发展时可以仅确认历时，不编造事件。未确认、失败或取消后保持暂停；重新保存设置可恢复，刷新不会自动重试。页面需要保持运行，并配置可用 AI。

缺少标签、模糊日期、日期倒退、纪元改变或变量尚未就绪时跳过，可选择显示原因或仅保留状态提示。来源、目标世界和倍率等配置改变会重新起算。改写、重抽或删除时间来源时回退相关演化和检查点，不按电脑时钟补算。

验证：自动测试覆盖解析、间隔、倍率、失败暂停、确认提交、备份、撤销和来源回退；本地浏览器模拟宿主完成自定义标签设置、无模型读取测试、阈值触发、候选确认、刷新恢复，检查 1440/390/320 像素宽度。尚未在真实 SillyTavern、玩家 MVU 脚本及真实模型服务中验收。
