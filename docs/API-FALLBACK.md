# 按任务配置备用 API

在“AI连接与方案 → 按任务选择模型”中选择主连接，并展开本任务“备用 API”选择备用1、备用2。留空为关闭。备用顺序保存到账户设置，各聊天共用，不进入聊天备份；保存普通连接时不会覆盖较新的备用设置。删除连接方案会清理对应备用引用。

每次请求只在明确网络失败、查询超时或 HTTP 408/429/500/502/503/504 时切换下一条已配置连接；每条连接只尝试一次，最多主连接加两条备用，不再从头循环。相同实际传输（地址、模型、凭据；酒馆连接视作同一传输）的别名去重。主连接成功立即停止。HTTP 400/401/403、无有效正文、JSON解析错误、档案校验错误、取消和上下文变化不触发备用。

超时或网关错误不代表上游未计费；备用调用可能另计费用。备用提高失败时的可用性，不是加速正常请求的方式。每条连接沿用自己的超时与输出限制，世界书初始化仍有现有600秒等待下限。

主连接和备用使用同一份已准备提示，不重复读世界书或修改全局当前连接。高级太始天每个专职任务独立选择备用；任一并行专职的候选链包含酒馆连接时改用串行，避免酒馆原始生成接口互相争用。玩家取消将阻止后续备用；酒馆远端生成可能仍在结束，返回不会写入。

悬浮窗显示实际连接、模型及备用序号，日志记录尝试序号、上限、错误类别和切换连接名称，不记录Key。成功返回仍走原有解析、快照校验和确认保存流程，备用本身不提交档案或发放收益。

本实现已用模拟接口验证；真实API故障切换及真实酒馆安装需另行验收。已发布1.3.7 ZIP未覆盖，本次暂不升级版本号、安装或发布。

验证记录：全量离线回归947项，934通过、0失败、13跳过；模拟浏览器在1440、390、320像素宽度通过配置保存、刷新恢复、备用显示与无横向溢出检查。测试未调用外部API，不代表真实酒馆安装验收。
