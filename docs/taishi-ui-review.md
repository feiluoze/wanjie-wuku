# 太始天测试反馈修正

本轮范围：世界书构建来源、对象详情阅读、众生与文明的已有数据展示。未改变 AI 连接、已保存档案或玩家实际拥有的成果。

| 不合理的逻辑 | 本轮修正 |
| --- | --- |
| 专用构建直接继承全插件共享参考，夹入其他模块规则 | 构建入口单独选书和条目，按当前聊天内的太始天档案保存；不跟随角色新绑定的书，不自动继承旧共享选择 |
| 构建页只有批号，范围不直观 | 展示所选书名与条目数量，提供“选择世界书 / 词条”；保存范围不调用模型，变化后清除旧批次游标，已有档案保留 |
| 网格的下一排被最长卡片推下，短卡片下方大面积留白 | 详情按列紧凑排布，手机单列；保留所有非空事实，不为填空编造内容 |
| 浏览世界详情时直接接上一整页保存差异 | 发展记录默认折叠，可展开和继续分页；核对依据、手工纠正也保持折叠 |
| 主界面成果与管理信息混杂 | 太始天整理记录、正文记忆设置、拟定与自动更新设置折叠；众生与文明的创建管理操作折叠，先显示已保存轮廓 |
| 长篇帮助占据阅读空间 | 主面板和对话框中独立的长帮助段落收进“使用说明”，原有折叠内说明不重复包裹；表单字段及其标签保持可用 |
| 世界字段已保存势力和社会描述，文明分类仍显示空白 | 从世界档案投影时代、主要势力与资源轮廓，链接原世界；明确区分轮廓数量和独立文明档案数量，不拆分或重复保存档案 |

界限：错误、进行中状态、待确认结果、实际候选和取消入口保持直接可见。为执行玩家点开的建档、连接配置等操作所需的表单，不整体隐藏。没有读取到的文明内容仍不自动补造，世界轮廓不等于实际获得组织、资源或能力。

验证：本地模拟宿主检查独立范围实际模型输入、选择持久化、修改范围保留档案、历史折叠和展开、手机布局、文明轮廓关联及帮助不隐藏状态/错误/输入。真实酒馆显示仍需安装后刷新验收；没有真实模型调用或 Git 发布。
