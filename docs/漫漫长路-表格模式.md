# 漫漫长路表格模式（本地开发）

本轮沿用现有八部：随身福地、宗门、万法图谱、本体修行、法器丹药、器灵伙伴、玄黄舰、研究工程。没有再扩建子表，没有第二份存储，也不改变原文规则、智能规则注入、候选确认或成果保存方式。

## 怎么查看

进入修行道场后默认显示表格。“表格 / 简报”只改变显示方式，旧简报保留。

- 总览列出名称、状态、所属八部、当前情况和操作。
- 选中一部后，表格显示该部三个关键字段，例如万法图谱的共同原理、掌握与验证、已验证效用，研究工程的已经发现、已可用所得、未解决条件。
- 分类下拉框与侧边八部入口都可以切换模块；切换分类会清空筛选。
- 可按名称或任意已有字段内容搜索，按四种状态筛选；每页最多20项。数量与单位按原文显示，不相加、不换算。
- 点击名称或“详情与修正”打开原档案。完整字段、关联和成长历史仍在那里，不因表格只展示关键列而丢失。
- “基于此参悟 / 继续此课题”等操作仍进入原有方案流程，点选只是准备草稿；实际生成才会调用配置的AI。
- 手机端表格内部可横向滑动，名称列保持在左侧；面板本身不横向撑宽。

## 数据边界

表格直接读取原 archiveId 对应的档案，不复制对象、不迁移、不删除、不批量改账。“计划中”“进行中”“已建立”“已结束”明确区分；已有研究方法不等于实物交付。

旧格式没有专用字段的记录显示“旧档原始内容”，保留原有标签和文字，不把一般描述冒充境界、数量或其他新字段。表格单元格可能截断预览，完整内容通过详情查看。

搜索、分页、分类、显示方式和滚动仅属于本地UI状态，刷新当前面板可保留筛选与焦点；更换聊天清空该聊天的筛选，不写入游戏档案或世界书。不新增自动结算，不更改角色MVU，不启动真实模型请求。

## 验证与交付状态

验证包括八部字段映射、四种状态、未知值保留、数量单位、隐藏字段搜索、分页、旧格式回退、HTML转义、显式关联、结束记录的操作禁用以及聊天筛选隔离。浏览器用本地模拟宿主覆盖1440/390/320宽度与深浅主题，并检查详情、筛选、刷新、表格滚动和存档不变；另保留原简报方案流程回归。
