# 第五批长期子表：先论必要，再补记忆（仅本地）

本批审查心智魔方、旅法师、一言为定，决定新增4类默认长期对象表。当前共26个已审词条，其中23个有默认表，合计30类；另有53类仅兼容旧档。前23词条收拢后的26类保持不变。

## 为什么留下这4类

| 词条／子表 | 原状态栏为何不足以单独承载 | 应长期记住 | 不应记录 |
| --- | --- | --- | --- |
| 心智魔方／重要伙伴（复用partners） | 原文总览只列重要个体，且明确详细能力、经历与关系按需展开。不同伙伴有自己的身份与人生，不能被当前部署覆盖。 | 独立身份、原型与具现方式、重要专业能力、关键关系与成长、仍有后续的部署或改造。 | 每次说话、训练、修复、重新出现；普通同型群体不强制全员逐一建档。 |
| 旅法师／重要坐标与地印（复用places） | 当前位面和重要地印摘要不能替代多个可再次往返的地域联系。每个地域可以独立锚定、供能或改变通路。 | 位面与地域、实际已知坐标、锚定与供能状态、影响后续往返的重要事实。 | 每次走路、短距传送、路过地点、每次重访；没有依据的地印或源地财物归属。 |
| 旅法师／重要旅法谱库（复用repertoire） | 原文明确“重要新增或完成……其余归档”，旧术式不应因本轮没展示就丢失。 | 可再次调用的术式、重要知识与规则样本、真实来源、已知与未知部分、实际可用形式。 | 每次施法、同一术式的改名或复述；普通见闻不全量入库，也不把部分理解升级为全知。 |
| 一言为定／长期诺契（复用promises） | 多个已选择参与的独立约定有不同义务、期限和持续权益，总览只展示当前执行重点。需要保存原条款以免后来被新条件覆盖。 | 原发诺来源与条款、真实履约进展、持续权益与到期条件、实际重要交付及成本保全依据。 | 路过告示、未选择的要约、普通即时交易、每期收款流水或独立奖励表。 |

这不是又建一张“待兑现奖励表”：诺契条目以一个重要约定为身份，未完成义务、未来适用条件与持续权益归同一条款；单纯已经到账的普通奖励不因此建档。是否达到长期重要门槛仍需按正文判断。

## 只用已有模型，避免再拆

不新增record schema，不引入新存储、外部数据库或余额账本；沿用现有ChatStore档案、稳定ID、候选确认和局部更新。

- 心智魔方的舰装性能、投入与关键改造进展，只有明确所属时才进入原伙伴的“相关进展与已得成果”。共享设施、不能归给单一伙伴的事项和保留原型仍按原状态栏保存；不猜主要所有者，不复制到每个伙伴。原型可复用不代表额外实物。
- 旅法师的火花空间经营、当前召现、有效契约、立界徽与持续安排仍按原文状态栏维护。它们不是坐标或术式的必然附件，不强塞归属，也不因未另设子表而停止记忆。
- 一言为定所有义务、实际交付与持续权益写在原诺契，未来给付不冒充本轮到账。发诺者死亡、破产或反悔不自行撤销已成立权益；不替玩家履约、不补算收益、不按电脑时间结算。

本批另有4个现成旧分类（心智魔方rigging/prototypes，旅法师space/manifestations）仅保留旧档查询、详情、历史和原ID更新。无旧记录时不发送其字段定义；显式insert不能新增，旧版省略operation的协议保持兼容。没有迁移、合并或删档。

## 接续与取舍

同型新个体必须正文确实诞生且身份明确才新增；召回、受损或重构不变成新伙伴。地域从坐标到永久地印沿原ID；不同位面同名地域明确区分。术式补全、转译与深化沿原条目，真实形成的独立融合才另名。诺契持续执行沿原约定，独立来源和义务不同的诺契不因报酬同名而合并。

已稳定且没有新信息的内容不重复提交，重要旧事实在局部更新时保持。普通日常过程进入叙事，未成为长期对象；不以字段合法来保证模型的语义判断一定正确。
