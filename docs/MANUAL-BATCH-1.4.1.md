# 手动分批与关系操作

## 分批整理

1. 在词条首页的更新控制区点击“手动分批整理”。选最近层数或起止楼层；填写每批角色正文数和字符上限。
2. 点击“划分批次”，不调用模型。计划固定当前终点，只存坐标和指纹，不另存正文副本。
3. 点击“整理下一批并预览”，接受本批全部有效变化且校验完整后推进。部分接受可以保存成果，但当前批保留待重查。
4. 也可明确选择“连续整理并保存”，消耗所选API额度。遇失败、部分校验或待确认对象停止；取消后已保存批次与日志保留。没有刷新后自启动。
5. 点击原入口继续；刷新、取消后的未保存候选需要重查。结束计划仅移除断点，不删除成果。新划分可重新核对范围，不直接重复结算。

一次只跑一个计划。未完成计划暂停该词条后台自动整理，其他词条照常。改写或重抽原计划内容时重新划分，插件不把新分支当作已处理。

## 势力人物与关系

太始天“创建与资料管理 → 指定人物 / 势力关系”选择已有世界、两端人物或组织，填写方向、状态、原因与来源事件。可选已有事件ID。保存不调用模型，不授予眷属身份。

手写关系默认保护；修改时沿用已有关系档案。关系详情的编辑表单可取消保护后保存；人物编辑表单可以保护social与relationship。眷属身份在“人物筛选 / 眷属身份”单独确认，更新筛选不会取消身份。

组织和区域详情可查看所属人物；人物详情显示世界、组织、区域和相关关系；关系详情可点回两端及来源事件。所有跳转读取现有档案，不复制对象、不自动反向推导关系、不传播秘密。

自动化只能验证固定测试与模拟宿主；真实模型的归属和关系提取仍需查看预览。发布前在真实酒馆验证自己的备份、分批取消/刷新与跨模块导出。
