# 插件 AI 参考世界书（1.3）

入口：连接设置 → 插件 AI 参考世界书；桌面也可从管理与备份进入。

- 默认不附加，旧聊天保持原有行为。
- 手动选择最多8本世界书，按标题搜索并勾选条目，全选仅操作当前筛选显示的条目。
- 跟随角色卡使用公开只读 `/getcharbook type=all create=false` 获取主世界书和附加世界书，群聊使用手动选择。新绑定的书默认选择启用条目，已有空选择保留。
- 预览和保存重新读取最新内容；每次插件 AI 请求也重新读取。普通参考限800000序列化字符，合并参考限1200000；太始天分批构建独立手选来源，最多4000000序列化字符，并按批发送，缺失条目或超限阻止发送并提示。
- 只在当前聊天保存书名与条目ID，备份可携带选择；不复制世界书正文，不修改原世界书。条目 ID 改变时重新选择。
- 手动勾选明确绕过正文触发条件，已禁用条目只有明确勾选才提供给插件 AI。它不改变主叙事的世界书触发。
- 附加资料放入 attachedWorldbooks 数据字段，系统提示明确区分设定参考与剧情证据。沿用原来源校验、变量写回规则。
- 太始天构建不继承共享选择；其他插件 AI 任务复用中央 query；不增加一次独立模型调用。发送摘要仅保存内存中的条目标题、字数、指纹、状态，不保存 Key 或完整响应。

验证：离线与模拟浏览器检查通过。实际模型上下文与服务端超时受所选供应商限制。插件选择不修改酒馆原世界书。
